# 歴史の航路

[ブラウザでアプリを開く](https://raw.githack.com/kmc2525-beep/dogaria/history-voyage-app/dist/index.html)（GitHubの公開ソースを外部サービスで表示。初回は「Open the page」を押してください。）

添付された歴史教科書 p.59–63、66–69 の内容を対象にした、ブラウザで使える学習アプリです。アヘン戦争、日本への影響、ペリー来航、開国、明治維新と諸改革から出題します。

## 機能

- **4択**: 年号、条約、港、改革名など、混同しやすい選択肢を各問に設定。
- **記入**: 答えを自分で入力。全角半角、前後の空白や中黒などの軽い表記差を吸収します。
- **遊び心**: Canvas製の2D横スクロールアクション。移動・ジャンプで障害物を避け、10本の旗で歴史問題に答えます。キーボードとタッチ操作に対応。
- **復習**: 正解や連続正解で次回以降の出題確率が下がり、誤答した問題が出やすくなります。10問内では重複しません。
- 単元選択、苦手優先、端末内の学習記録、記録リセット。アカウント不要。
- **動画広告**: 起動45秒後に中央の大きなカードを表示し、以後3分ごとに30本からランダムに表示。右上の×で閉じられ、クリックで元のYouTube動画を新しいタブで開きます。サムネイルはYouTubeの画像URLから読み込みます。公式の人気動画紹介と月間ランキングから選定し、再生数は掲載時点の参考値です。

`dist/index.html` をブラウザで開くだけで動きます。GitHub Pagesを利用する場合は `dist/` の内容を公開ブランチのルートまたは `docs/` に配置するか、Actionsで `dist/` をデプロイしてください。外部との通信はWebフォントの読み込みのみで、学習記録はlocalStorageに保存します。

問題・解説は添付画像から作成したオリジナルの短文です。教科書の紙面画像や本文の転載は含めていません。
